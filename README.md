A one-image editorial poster summing up Thursday 19 November 2026: Grand Theft Auto VI finally opens in Vice City after a 13-year wait, the World Court rules on the Rohingya genocide case, Trump, Xi and Putin meet in Shenzhen, Jeffries is nominated for Speaker, Cyclone Akvan closes in on India, the EU proposes a €45bn loan for Ukraine, and Voyager 1 reaches one light-day from Earth.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3 standard library only, no network, no clock) copies the
rendered `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`. To re-render the
poster from scratch, run `python3 build_poster.py` (needs Pillow and the
bundled DejaVu fonts in `fonts/`); re-running it reproduces `entry.png`
byte for byte.
